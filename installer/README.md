# @qdock/installer

Official CLI installer for QDock on macOS.

## Usage

```bash
npx @qdock/installer
```

### Options

- `--channel stable|beta` (default: `stable`)
- `--dir <path>` (default: `/Applications`)
- `--no-launch`
- `--verbose`

## Development

Run locally:

```bash
node bin/qdock-installer.js --help
```
